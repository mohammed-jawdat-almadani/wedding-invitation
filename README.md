# Melisa & Kerem — Düğün Davetiyesi (Lacy Deluxe)

موقع دعوة زفاف رقمية فاخرة بنقوش دانتيل ولؤلؤ وأبواب ثلاثية الأبعاد تفاعلية، مستوحى ومطابق بنسبة 100% لتصميم Invitely Lacy Deluxe الأصلي.

## ✨ المميزات
- أبواب مزدوجة عاجية ثلاثية الأبعاد تفتح بحركة سينمائية عند اللمس.
- موسيقى أصلية نقية تعمل في الخلفية مع مشغل صوتي عائم ومؤشر ذبذبات صوتية متحرك.
- 11 قسماً متكاملاً:
  1. الغلاف (Hero): Melisa ve Kerem.
  2. نص الدعوة والعائلات: Yıldız & Demir.
  3. التاريخ والوقت: 08 AĞUSTOS 2026.
  4. الموقع والخريطة: Four Seasons Hotel Istanbul Bosphorus مع توجيه مباشر لخرائط جوجل.
  5. العداد التنازلي الحي للأيام والساعات والدقائق والثواني.
  6. برنامج الحفل (« Günün Çizgisi »).
  7. قائمة الطعام (Menü).
  8. جدار الذكريات والصور (« En güzel anlarımız »).
  9. لعبة أسئلة تفاعلية لطيفة (« Biraz Eğlence! »).
  10. نموذج تأكيد الحضور (RSVP) مع حفظ محلي واحتفال جزيئات الذهب.
  11. شاشة الختام الملكية.
- دعم كامل للغتين: التركية الأصلية والعربية الفصحى مع دعم RTL تلقائي.
- متجاوب بالكامل: مخصص للهواتف، ومحاكي آيفون فاخر لشاشات الكمبيوتر.

## 🚀 التشغيل المحلي
```bash
npm install
npm run build
npm start
```
أو بالنقر المزدوج على `start_invitation.bat`.

## ☁️ النشر على Railway
المشروع مهيأ وجاهز للنشر المباشر عبر `railway up` مع ملف `railway.json` وخادم `server.js`.
